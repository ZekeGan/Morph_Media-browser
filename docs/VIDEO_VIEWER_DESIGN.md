# 影片播放器

> 最後確認：2026-11-05。只寫現行規則；選型與歷次取捨見 [決策索引](DECISIONS.md)（C-83～C-85）。程式：`src/VideoViewer.tsx`、`src/VideoControls.tsx`、`src/VideoSubtitleSettings.tsx`、`shared/subtitles.ts`；測試：`tests/video-player-ui.ts`、`tests/video-failure-ui.ts`。影片從媒體頁的大視窗（`MediaViewer`）或右側面板的檔案預覽開啟，入口與佇列見 [媒體工作區](MEDIA_WORKSPACE.md#統一媒體工作區)。

<a id="現行控制欄2026-10-28"></a>

## 播放控制

YouTube 式控制列；「放大／縮小」只指進入／退出全螢幕，不做畫面放大平移或劇院模式。使用 Video.js 媒體元件，控制列由 `VideoControls` 組成，共用同一個 HTMLVideoElement。

- 上排：可拖曳進度、緩衝範圍與滑過時間。下排：播放／暫停、上一部／下一部（有播放清單時）、音量／靜音、時間、更多播放設定、全螢幕。沒有快退／快進按鈕（快捷鍵保留）；窄區域固定分行，避免音量展開時改變喇叭位置。
- 播放時閒置約 2.5 秒隱藏控制列；滑鼠移動、鍵盤聚焦、暫停、設定開啟、音量拖曳或錯誤時顯示。控制列外層透明，只有按鈕群組使用半透明圓角底。音量平常只顯示喇叭，hover／聚焦展開滑桿，點喇叭切換靜音。強調色、圖示與語言沿用全域設定。
- 全螢幕由播放器容器使用 Fullscreen API，保留同一播放實例與控制列；按鈕、F 或雙擊切換，Esc 退出。更多面板與字幕選單留在容器內、限制寬高可捲動；Esc／關閉收起並把焦點還給齒輪。ESC 一次只退出最上層（先退出播放器全螢幕）。
- 快捷鍵只在播放器有焦點時作用：K／Space 播放暫停，J／L ±10 秒，左右 ±5 秒，上下音量 ±5%，M 靜音，C 字幕，F 全螢幕。播放速度 0.5～2 倍，本次瀏覽切換影片時保留。

<a id="播放設定-ux2026-10-28"></a>

## 播放設定

「更多播放設定」面板：倍速與播放選項在上，字幕的「來源／同步與編碼／外觀」收在預設收合的「字幕設定」群組。調整即時預覽，明確保存才寫回；保存失敗保留草稿與原因。面板依播放器的深色半透明風格設計，限制在播放器內，適應窄視窗與全螢幕。

- 沒有「自動播放」「播完接下一部」開關：開啟影片即播放；自動接續是播放佇列的設定（見 [媒體工作區](MEDIA_WORKSPACE.md#跨專案影音佇列與迷你播放器)）。

<a id="移除-cc-按鈕待實作"></a>

## 字幕入口

字幕顯隱、載入與設定都在播放設定的字幕群組：群組內有顯隱開關（未載入字幕時停用），來源子群組負責載入／移除。控制列沒有 CC 按鈕；保留字幕拖入、C 快捷鍵（沒有字幕時直接開啟來源群組）。

## 播放生命週期

- 同時只有一個播放實例。開啟影片即播放；不記錄或恢復觀看進度。
- 音量與靜音存在本機 `workspace-ui.json` 的 `videoAudio`，不寫入媒體或可攜記錄。取得偏好前維持靜音；只有使用者修改才排程保存，失敗時照常播放並顯示原因。
- 切換影片、定位進度、開啟更多設定、離開內容或隱藏應用都會取消待播動作。離開資料夾／專案即停止並釋放影片來源；隱藏或最小化時暫停，重新顯示不自動恢復。除 DOM 可見性外也監聽原生 `window:state.visible`。
- 卸載時從實際媒體節點暫停、移除 src 並取消載入；只允許仍掛載的節點啟動播放。
- 切換影片時清掉上一部的字幕與拖入清單；過期的載入結果不套用到新影片，載入／解析失敗保留原字幕。
- 跨專案的影音佇列與迷你播放器由 [媒體工作區](MEDIA_WORKSPACE.md#跨專案影音佇列與迷你播放器) 持有。

## 檔案與格式

**介面套件不等於解碼引擎**：能否播放取決於 Electron／Windows 的媒體後端，容器與內部編碼是兩回事，不能只看副檔名。[媒體容器與編碼說明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats/Containers)

| 類型 | 現況 |
| --- | --- |
| MP4（H.264／AAC）、WebM（VP8／VP9／Opus／Vorbis） | 可播放 |
| 外掛 SRT／WebVTT 字幕 | 支援：拖入、切換／關閉、時間調整、外觀；SRT 解析成播放用 cue，不改原檔 |
| HEVC、AC3／DTS 音訊、10-bit H.264、AVI／WMV、多數 MKV | 不保證；失敗時見 [播放失敗說明](#播放失敗說明)，不轉檔，用外部播放器（[C-129](DECISIONS.md#c-129影片格式維持現狀播不了就用外部播放器2026-11-05)） |
| ASS／SSA、內嵌字幕、圖形字幕、多音軌 | 不支援；沒有解析能力時標示未支援，不顯示成「沒有字幕」 |

- 原始媒體透過 `media://file/<rowId>/<fileId>` 與 `Explorer.stream` 串流讀取（Range／206／416 與取消）；可攜資產用 `media://asset`。只用受控資料夾／檔案識別，驗證實體路徑、junction／越界與 MIME，renderer 不能讀任意絕對路徑；大檔不經 IPC 轉 Base64。
- 縮圖等可重建資訊放本機快取，按需取得，不複製原片。
- 檔案清單中，其他檔案（含 EXE／腳本）只顯示名稱、類型與大小，不提供執行動作。

## 拖入字幕與同步設定

1. 字幕檔可拖到播放器：有目前影片且格式支援時立即套用，不重播或換片；不支援或解析失敗顯示原因並保留原字幕；未選影片時先引導選片。
2. 同時拖多份時列出來源供選擇，一次顯示一條，可切換／關閉，不自動合併成雙語。從檔案總管拖入由 preload／main 驗證實際檔案，不接受任意字串路徑。
3. 資料夾內的字幕用相對引用，不複製；外部拖入只作本次播放來源，要跨設備保存需明確匯入成可攜副本（存在 `details.subtitles`）。
4. 文字編碼預設 UTF-8，亂碼時可改選 Big5 或 Shift_JIS，不覆寫原字幕。不自動以同名字幕取代使用者的選擇。

| 問題 | 處理 |
| --- | --- |
| 整段字幕太早／太晚 | 提早／延後 0.1 秒、直接輸入秒數、重設；正值＝晚出現 |
| 開頭同步、越播越不同步 | 提示可能是不同剪輯或幀率的字幕，建議換字幕；不支援兩點校正 |
| 字太小、看不清或太靠下 | 字體／大小、文字與背景或描邊、底部距離、重設；位置依實際影片畫面計算 |
| 縮放／全螢幕後位置 | 依實際影片顯示區定位，保留控制列的安全空間 |
| 拖曳進度／倍速／暫停 | 以媒體播放時間為字幕時鐘，seek、換片、重播同步更新；換來源時釋放舊軌 |

時間校正按「該影片＋該字幕來源」保存在資料夾的可攜記錄（`SubtitlePrefs`），不影響其他影片；原影片與字幕不修改。契約見 `shared/explorer.ts`。

## 影片佇列展示

大視窗的影片清單可切換「清單／圖片」兩種呈現：圖片模式以縮圖呈現同一份項目，選取、排序與播放不變。每次開啟預設清單模式，展示方式只在當次檢視保留；縮圖按需載入，失敗有佔位，不建立多個播放實例；切換不重建播放器、不換片。全域混合佇列的呈現細節見 [未決項](OPEN_DECISIONS.md#媒體新版待討論細節)。

## 播放失敗說明

瀏覽器引擎只回報「無法解碼」，所以失敗時播放器讀取檔案開頭 16 位元組（`fileProbe`）：是 ZIP／RAR／7z、網頁或空檔就直接說明原因；並提供「用系統預設播放器開啟」（`openFile`，僅限影音檔）與「在檔案總管顯示」（`revealFile`），只在使用者按下時執行。其他無法解碼的情況顯示通用說明。

<a id="剩餘規格及驗收"></a>

## 驗收

受控樣本涵蓋大小檔、拖曳定位、音訊、切換影片時釋放、無權限／檔案搬移、只有圖片、格式不支援與原始檔不變；字幕涵蓋拖入、失敗保留、亂碼、不同影片不串設定、正負延遲與重設、seek／倍速／暫停／重播、窄窗與全螢幕定位。依修改範圍選 `video-player-ui` 的群組（`--group controls|subtitles|appearance`）。
