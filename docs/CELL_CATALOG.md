# CELL 目錄

此頁區分現行契約與候選；共用編輯行為見 [EDITOR_DESIGN](EDITOR_DESIGN.md)。值、版面及受控動作分開；舊 DataType 不作目標範式。

## 現行契約

[CellKind](../shared/model.ts) 與 runtime 驗證是程式真相，新增種類需同步 renderer／驗證／可攜相容性。

| kind | 用途 |
| --- | --- |
| game-launch | 遊戲專案專用的啟動按鈕（2026-11-02）：可用 `actionId` 指定要啟動的動作（EXE、指定應用程式開啟檔案或資料夾內捷徑），未指定時用預設啟動動作，再退回第一個可啟動的動作；使用資料夾已綁定的目標；未綁定時停用並提示，啟動前依現有規則確認；與遊戲頁的按鈕共用同一個 `runTarget` 驗證，不擴大其他組件的動作權限 |
| name／path | 目前資料夾系統名稱／路徑，不把舊設備路徑當可攜原值 |
| field-text | 依 attributeId 顯示文字 |
| field-tags | 多值標籤 |
| field-number | 數字 |
| field-date | 日期時間 |
| field-boolean／field-enum／field-url／field-date-only | 是／否、單選、網址、純日期 |
| static-text／spacer／system-info | 固定文字、占位間距、系統資訊 |
| image | 選用的獨立圖片組件；每個位置可各自選圖，空白不強制填寫 |
| divider | 分隔線，沿用組件尺寸／文字色 |
| open-folder | 經 main 驗證後開啟目前資料夾 |

缺 key 可顯示預設，但不寫回資料夾、不成為搜尋真值；搬入專案的欄位身分不可只按相同 alias 合併。

遊戲的 EXE／資料夾按鈕已有專屬工具列與獨立目標／參數，見 [遊戲](GAME_VIEWER_DESIGN.md)；不因此擴大所有 CARD CELL 的動作權限。

## 新增組件與型別

2026-10-28 使用者確認新增以下三種基礎組件與四種欄位型別；已接入 CellKind、編輯器、資料欄位、搜尋／排序與可攜保存；schemaVersion 維持 1。

| 基礎組件 | 目標行為 |
| --- | --- |
| 固定文字 | 文字保存在版面，用於標題／說明；不建立資料欄位或複製到各資料夾 |
| 空白間距 | 可調寬高並實際占用格線，抵抗自動向上排列；編輯時顯示虛線，瀏覽時透明 |
| 系統資訊 | 提供分類、檔案數、容量等系統／衍生資訊，使用既有索引或快取；未取得或未計算需明示，不為渲染卡片逐筆同步掃描 |

| 欄位型別 | 目標行為 |
| --- | --- |
| 是／否 | 支援未填、是、否；未知不能當作 false |
| 單選 | 用於狀態等受控選項，選項可管理，避免自由輸入造成名稱不一致 |
| 網址 | 驗證網址，可顯示自訂文字並透過受控入口開啟連結，不擴大為任意系統命令 |
| 日期 | 與日期時間分開，用於發售日／購入日等，不強迫補時間或時區 |

新增型別一併支援 CELL 顯示、資料夾設定編輯、搜尋／排序、值驗證、可攜保存及舊資料相容，不只增加選單。空值不寫假資料；型別儲存與查詢契約由 shared/fields.ts 與驗證持有，未因此授權批次遷移實際收藏。

評分先作為數字欄位的顯示方式，多行長文字先作為文字組件的呈現設定；不另新增獨立資料型別。操作區與方案管理見 [編輯器](EDITOR_DESIGN.md#組件與方案管理)。

## 後續計畫與保留候選

### 遊戲封面圖片組件

已實作（2026-11-01）：積木編輯器在遊戲模式新增「封面圖片」組件，顯示該資料夾既有的遊戲封面，與可各自選圖的一般 image 組件區分；沿用遊戲封面資料來源，不另建立重複封面欄位。非遊戲模式不提供此組件；缺少封面時使用佔位並填滿組件。圖片類組件可選「填滿容器（裁切）」或「完整顯示（保留空白）」（imageFit），遊戲封面預設填滿、一般圖片預設完整顯示（2026-11-01 修正縮放後圖片不貼合容器）。此項不改變既有遊戲邊界與封面匯入規則，見 [遊戲內容](GAME_VIEWER_DESIGN.md#1-已確認的遊戲內容頁)。

圖片填滿方式有三種：填滿裁切（`cover`）、完整顯示留白（`contain`）、完整顯示並以自身模糊放大圖填滿空白（`blur`，2026-11-02 新增）。封面常為長圖或寬圖，裁切會切掉標題字，故遊戲封面組件未設定時預設為 `blur`；已明確選 `cover`／`contain` 的組件維持原選擇，一般圖片組件預設仍為 `contain`。

### 其他後續項目

群組（group）已於 2026-11-01 移除：效益小、需決定的規則多。載入舊專案時自動略過群組及其子組件（`withoutGroupCells`），下次保存才寫回。

尚未核定的擴充包含富文字、更多衍生值（如時長）、更完整數值格式與單位、日期精度／時區等，需要逐項規格及排程。來源日期不能與系統／購買時間混用；只有年／年月的資料不能硬補日期。

候選的來源、renderer、格式／空值／樣式及操作需各自明確；衍生值標示計算狀態／更新時間，不阻塞基本列表。其他外部應用不得變成任意系統命令輸入。更完整例子見 [封存目錄](history/agent-docs-before-cleanup.md#cell-catalog)，不是本輪必做清單。

系統檔案數與容量採已開啟內容的直接檔案快取，顯示最後計算時間；未知顯示「尚未計算」，不在卡片渲染時掃描。網址只允許 HTTP(S)，拒絕內嵌帳密與系統命令；單選定義 1～100 個唯一非空選項，已不在選項內的舊值仍可讀取，寫入新值時驗證。純日期檢查真實曆日，是／否以 null 表未填並保留 false；未知舊型別原樣保留。入口 shared/fields.ts、src/folderStats.ts、tests/decided.test.ts。

## 編輯器操作（2026-11-01）

- 欄位只改顯示名稱可重新命名：欄位清單的鉛筆圖示，或組件設定「綁定欄位」旁的鉛筆；同名（不分大小寫）即時拒絕。型別建立後不能改，要換型別需刪除欄位重建。
- 單選選項：正在被資料夾使用的選項不能移除，並顯示使用中的選項與數量；組件條件的比較值改為選項下拉。選項不提供改名與排序（改名需批次寫入資料夾記錄，未核定）。
- 組件設定分為「內容／顯示條件／位置與大小／樣式」可收合區塊，移除鈕固定在標題右側；有顯示條件的組件會自動展開條件區塊。位置輸入限制 X＋寬 ≤ 12。
- 名稱：「固定文字」改為「版面文字」（只存在版面），「自訂文字」改為「文字欄位」（綁定資料）；組件按鈕與設定標題皆有一行用途說明。

## 文字、數字與條件的呈現設定（2026-11-01 核定）

- **長文字**：名稱、路徑、文字欄位組件可勾「長文字換行顯示」（`wrap`）；預設維持單行、過長以「…」截斷。不改原值。
- **字級與對齊**：所有組件的 `style` 可選字級小／中／大（`fontSize`，各組件基準大小的 0.85／1／1.4 倍）與靠左／置中／靠右（`align`）；缺省為中與靠左。粗細、邊框、內距延後。
- **數字**：組件可設小數位數 `decimals`（0 到 6，缺省依原值）；一般文字呈現可設單位文字 `unit`（≤20 字）與位置 `unitPosition`（前／後，缺省後）。評分與進度只套用小數位數，不顯示單位。皆不改欄位原值。
- **顯示條件**：除有值／未填／等於／不等於外，數字、日期、日期時間欄位可用大於（`gt`）與小於（`lt`）；比較值須符合欄位型別，型別不符或未填一律不顯示。仍只能設一個條件。
- 以上皆為組件可選欄位，`schemaVersion` 維持 1；舊專案不需遷移。

## 備用欄位（2026-11-02 新增）

- 欄位組件（`field-*`）可在「內容」設定「備用欄位」：同型別欄位，最多 5 個，依序嘗試；第一個有值的欄位就是顯示（與複製）的欄位，兩者都有值時以排在前面的為準。空字串、只有空白、空清單算沒有值；數字 0、布林 false 是有值。全部都沒有值時回到主要欄位（維持原本的未填與型別不符提示）。
- 用途：不同來源網站的同義欄位（Steam 遊戲名、DLsite 作品名…）不複製資料，由組件決定顯示哪一個；不需遷移已匯入資料。搜尋、排序、篩選暫不支援多欄位組件。
- 編輯器：每個備用欄位一列（順位、下拉、上移、下移、移除）；「新增備用欄位」；下方說明預覽中的資料夾實際使用哪個欄位及各欄位有無值。欄位清單的「使用 N 次」含備用用途。
- 驗證：備用欄位須存在、與主要欄位同型別、不重複、不含主要欄位。刪除欄位時：被刪的是主要欄位則改以下一個備用欄位為主，是備用欄位則從清單移除。

- **啟動遊戲組件的備用動作（0.28.0）**：組件設定「備用動作」可列最多 5 個啟動動作；每個遊戲依序取第一個已綁定目標（種類相符）的動作，按鈕顯示實際使用的動作名稱；都沒綁定時顯示主要動作的「尚未綁定」。因此同一個組件可同時涵蓋 EXE 與捷徑的遊戲。尚未提供「逐個遊戲手動指定顯示哪個按鈕」，待使用者確認需求。

- **內容多時可捲動（0.30.0）**：文字欄位、標籤、版面文字組件可勾選「內容多時可捲動」，保持格子高度並以滑鼠滾輪或鍵盤捲動查看；開啟時一律換行顯示。未勾選時維持原本的截斷。

- **圖片組件依位置選圖（0.31.0）**：圖片組件「沒有手動選圖時」可設為「顯示資料夾內第 N 張圖片」（1～999）。依檔名自然排序，只看該資料夾直接包含的圖片（不含子資料夾、隱藏檔）；優先順序是資料夾手動選的圖 > 第 N 張 > 留空；該資料夾沒有第 N 張時顯示「沒有圖片」。以縮圖呈現，不複製或改寫原檔。

## 欄位呈現與互動

沿用既有欄位型別：enum／boolean 可選狀態徽章，number 可顯示評分或進度並設定滿分／總量；只截斷呈現，不改原值。欄位可啟用複製，0 與 false 保留；透過受信任主程序複製目前欄位，不開放一般網頁剪貼簿權限。

組件可依另一已綁欄位的有值／未填／等於／不等於決定內容顯示，保留格位以免版面跳動；編輯預覽仍可選取。條件欄位刪除時引用組件亦納入影響確認。公式與腳本仍延後；群組已移除。
