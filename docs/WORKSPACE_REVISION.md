# 工作區現行規則

> 最後確認：2026-11-10。外框、專案建立、三模式與右側面板的現行規則；檔案總覽與媒體頁在 [媒體工作區](MEDIA_WORKSPACE.md)。領域對應見 [areas.json](areas.json)（shell、browse、panel、project、backup），理由見 [決策索引](DECISIONS.md)（C-87 起）。

## 外框與專案區

- 頂部只有 Logo 與搜尋入口；搜尋範圍 SELECT 僅在搜尋跳窗內。搜尋預設／語法見 [搜尋規格](SEARCH_DESIGN.md)。
- Logo 下方工具列保留首頁 ICON；應用程式設定移到右上角全域標題列、視窗控制左側，含統一主題與語言，以及本機重新連結、匯入與全域清理。各專案選單內另有「專案設定」，不混在全域維護中。外觀保存與語言規則見 [共用 UI](UI_RULES.md)。
- 「我的群組」包含最愛、使用者自訂群組與未分類三種。專案未加入自訂群組才列未分類，收藏狀態獨立。當前一個專案的自訂歸組與排序由本機設定保存。
- 群組拖曳標題排序，以目標標題上／下半部決定插入前／後並顯示插入線；移除選單上下移動按鈕，鍵盤可用 Alt＋↑／↓。群組內專案沿用拖曳排序／移動。
- 群組與專案操作平時隱藏，僅該標題／項目 Hover、鍵盤聚焦或選單開啟時顯示；選取專案本身不讓操作常駐。自訂群組提供改名 ICON 與選單入口；最愛／未分類維持固定名稱。展開箭頭用名稱右方的圖示，隨收合狀態旋轉。
- 新增專案位於側欄最下方，用中性色；側欄可調寬、收合及捲動。群組內不設高度門檻或獨立捲軸；整欄仍可捲動，但隱藏捲軸外觀。右下角只保留錯誤、部分失敗與掃描進度；一般保存／切換不跳成功通知，來源匯入及資料夾清理結果留在操作頁。

## 建立與既有專案

建立順序：**名稱 → 分類 → 選資料夾 → 群組 → 完成**。群組預設未分類。資料夾先由原生選擇器選定，最後完成才開始建專案／掃描；取消不建檔。main 使用暫時選取憑證，renderer 不能任意指定未授權路徑。

新專案不預建欄位，預設只含名稱、路徑與開啟資料夾組件；既有欄位及資料不因升版刪除。新專案預設掃描全專案；遊戲邊界仍生效。既有有限掃描專案保留原涵蓋範圍，只能由明確的擴大掃描動作新增記錄。調 CARD 顯示或導覽不默默掃描／初始化資料。

## 中央版面與工具列

中央與右側是同層、互相獨立的內容區，右區使用完整可用高度，不嵌在中央內容卡片內。

1. 第一列中間選 CARD／TABLE／TREE；資料夾 CARD 的方案 SELECT＋相連編輯按鈕與模式選擇同列。方案及卡片顯示設定只在「資料夾＋CARD」出現，切成檔案模式即隱藏，即使保存的資料夾模式仍為 CARD。重新掃描已併入最上方應用程式列的單一「重新整理」按鈕（見下），「目前資料夾設定」ICON 放最右。
2. 第二列保留返回／前進與可逐層點擊的 Breadcrumbs，顯示路徑、筆數／層級等必要狀態。不重複專案名稱、根／父層按鈕、搜尋框或放大瀏覽按鈕；批次編輯暫不放工具列，資料 API 保留。
3. 其餘空間完整給 CARD／TABLE／TREE；CARD 分頁放內容底部。預設 CELL 背景透明。

## 三模式與開啟行為

| 模式 | 顯示範圍 | 雙擊左鍵 |
| --- | --- | --- |
| CARD 多層 | 同一畫面平鋪 ROOT 與其子資料夾；全部或 ROOT＝第 1 層至 N 層 | 保留中央範圍，更新共用目前資料夾與右側，不縮成子樹 |
| CARD 單層 | 初始顯示指定 N 層；進入後顯示該資料夾的直接子層 | 進入子層並更新右側，返回／前進同步 |
| TABLE（LIST） | 從 ROOT 開始，按目前所在資料夾逐層列出直接子資料夾 | 進入子層並更新右側 |
| TREE | 已建立且允許的完整階層可逐支展開，不受 CARD 顯示／分頁設定影響 | 更新共用目前資料夾及右側，保留整棵樹並定位該節點，不孤立成單節點 |

TABLE 可拖曳欄標題調整順序（或 Alt＋←／→），欄寬、排序與欄位身分維持獨立；順序依專案存於本機，移除的欄位忽略，新欄位附加於末尾。

所有模式提供以反斜線分隔的 Breadcrumbs；點祖先時更新共用位置與右側內容。Breadcrumbs 只回到目前位置的祖先，返回／前進維持瀏覽歷史，可回訪跨分支位置，因此先保留兩者。TABLE／CARD 單層點祖先會同步更新中央與右區；三模式共用目前檢視資料夾與返回／前進歷史，切換模式不恢復各自舊路徑。TREE 保留全樹並定位同一節點；CARD 多層保留專案範圍並定位同一卡片，單層／TABLE 顯示目前資料夾子層。

TREE 節點可收合／展開子資料夾；收合分支不加入 Dagre／React Flow 的節點及邊，非只用 CSS 隱藏。狀態依專案存本機，跨模式定位時只展開所需祖先。可調實作基線：初始顯示前兩層，同層超多時先收合該根；提供全部收合／重設展開，不改可攜資料或掃描範圍。

單擊選取並立即在右側面板顯示該資料夾的內容（中央不動，不進入；雙擊才進入並更新歷史，進行中的單擊預覽會先完成再進入；面板收合時單擊只選取，卡片／表格列的「顯示資料夾內容」圖示可針對單一資料夾打開面板；面板只由使用者開關，右鍵設定與預覽檔案屬明確操作才會打開；面板標題旁在選取不是中央資料夾時提供「進入此資料夾」；資料夾設定有未保存變更時，切換改在面板內以「放棄變更並切換／留在此處」詢問）；右鍵開啟資料夾設定，與右側內容不同層級。TREE 初始佈局與點擊不可因延遲 fit 產生跳位，選取不應重算 Dagre。

所有開啟／進入先由 main 驗證實際路徑、有效記錄及保護邊界，成功才改導覽歷史／右區。缺失、損壞、停止建檔或受遊戲邊界保護時提示「未建立」／「無法建立」，不進入、不自動補建；有效遊戲 ROOT 本身仍可開啟。早期唯讀繼續 API 不代表可繞過此規則。

## CARD 專屬控制

- 「顯示模式／每列筆數／每頁筆數」在 CARD 工具列的設定區，TABLE／TREE 隱藏。範圍模式／層級及每列／每頁密度直接排列在 CARD 工具列，以套用保存草稿；層數只列目前已掃描範圍的實際深度，不假設有 50 層，也不為取得深度額外掃描。
- **開啟專案的落點與末層**：CARD 單層的「第 1 層」是專案根；開啟專案時若根下有子資料夾，直接列出子資料夾而不是只有一張根卡片（沒有子資料夾才顯示根）。進入沒有子資料夾的資料夾時，中間顯示該資料夾自己的卡片；TABLE 仍是子資料夾清單，空時說明內容在右側面板。
- **顯示設定彈出面板**：層級範圍、顯示層數、每列卡片數、每頁筆數收進工具列右側的「卡片顯示設定」按鈕（按鈕文字摘要如「單層 · 第 1 層 · 每列 3」，中央區窄於 620px 只留圖示）。
- **窄視窗（≤1100px）**：右側面板為覆蓋層時，中央區以半透明遮罩變暗，點遮罩即收合面板。
- 同一區兩項顯示控制：多層／單層，以及層數；多層可選全部或 1～N，單層選 N。每列筆數依可用寬度自動減少，每頁筆數獨立。
- 方案 SELECT 與編輯按鈕指向同一個作用中方案。版面只影響呈現，不更改欄位原值或掃描涵蓋。舊專案只有原版面也可開啟，不強制遷移自訂 CELL 樣式。

### 設定入口圖示區分

CARD 範圍與密度的摘要直接顯示在上述按鈕上。工具列最右維持資料夾設定圖示；右側標題列亦提供同一設定入口，Alt+Enter 開啟目前資料夾設定。TABLE 提供可搜尋的欄位勾選選單，名稱必留，其他欄位可隱藏／恢復預設；顯隱、排序與寬度為獨立本機偏好，不改欄位資料。檔案模式的範圍資料夾、子層範圍、展示與類型整合到上方工具列；最上方應用程式列（應用程式設定齒輪旁）只有一個「重新整理」按鈕：重新掃描目前專案並重新載入右側內容（資料夾內容與檔案總覽），掃描中停用，寬度不足時分組換行。

### 資料夾頁共用外框

遊戲／漫畫／媒體等分類使用同一個外框：資料夾詳情（預設收合）、直接子資料夾，再接內容。遊戲專案裡非遊戲 ROOT 的資料夾使用統一資料夾頁（詳情／子資料夾／檔案），只有遊戲 ROOT 使用遊戲專用頁；漫畫作品保留圖庫與漫畫資訊 CELL。右側面板由 RightPanel 提供同一組標題列、分頁與捲動容器，全視窗覆蓋層共用 overlay-frame。

### 資料夾設定停靠

資料夾設定一律停靠在右側面板：設定是面板的分頁（內容｜設定），不另開抽屜或第三欄，分頁列右側有關閉設定的圖示；設定開啟時面板會自動顯示，開啟其他資料夾時設定跟著切換。`browse.settingsDock` 為舊偏好，保留可讀取但不再使用。切換分頁、關閉沿用「放棄尚未保存的資料夾設定？」確認。應用程式設定維持抽屜。

## 右側內容與覆蓋層

舊分類定義與適用中央檔案／單檔預覽保留讀取相容；圖片／影片／音樂／其他的資料夾內容已共用媒體頁。新版分工與影音背景播放由 [統一媒體工作區](MEDIA_WORKSPACE.md#統一媒體工作區) 持有，以下分類舊配置僅適用尚有呼叫的相容路徑，不能覆蓋共用新頁規則。

- 共用「返回頂部」固定於右側內容區右下角，只在目前內容可往上捲動（scrollTop > 0）時顯示；到頂、無捲動內容或內容切換後重新判定。只回捲該窗格，不捲整個應用；漫畫 TOP 也沿用此規則。

- 右側預設開啟並顯示 ROOT 內容；顯隱、目前對象及尺寸保存在本機設定。顯隱開關位於最上方全域工具列，沒有可瀏覽專案時隱藏；X 關閉與頂部切換狀態一致。面板只由使用者開關（工具列圖示、面板 X、卡片／列的「顯示資料夾內容」圖示），進入資料夾不改變顯隱；右鍵／Alt+Enter 開資料夾設定與預覽檔案是明確操作，會打開面板。舊設定檔的 `autoOpenContent` 欄位被忽略。
- 資料夾設定分「資料（含網站資料匯入）／圖片（選用）／進階」分頁，記住上次停留的分頁，遊戲另有操作設定：
  - 未保存的欄位在底部固定列提示，可保存或放棄。
  - 「共用資料／僅目前專案」切換在資料分頁並說明影響，只在其他已連結專案也顯示這個資料夾、或這個專案已有私有資訊時出現。
  - 網站資料預覽是現值／新值差異表；圖片以縮圖選單選擇、匯入或清除，圖片庫標示用途。
  - 頂部「還可以補上」卡片列出缺少的啟動檔、封面、作品資料並直達處理位置；未綁定的遊戲動作以強調色標出，可就地「測試啟動」。
  - 路徑縮成單行；「在檔案總管開啟」用右側面板標題列的圖示。移除更改內容資訊版面入口；私有覆寫、完整屬性／來源與清理均在進階頁。清理預覽、取消、確認及逐項結果直接留在此頁，沿用 token／指紋檢查，不開第二個彈窗。外側仍標示目前正在編輯共用或僅本專案資料，保留切換草稿保護。
- 資料夾內容依屬性切換；各類解碼與專用操作由專項文件持有。舊影片的播放器／檔案列上下配置只作相容呼叫規則，共用頁右側為檔案列表，明確開啟後由全域播放器接手。
- 設定 Drawer 的未保存變更受關閉保護；ESC 只退出最上層可關閉區域。工作區／閱讀器放大可用 ESC 退出。
- 所有捲軸採共用風格；焦點、快捷提示與保存規則見 [UI_RULES](UI_RULES.md)。沿用現有三套主題；品牌／專屬字型延後。

## 工作區介面細節

實作差距見 [當前工作](WORK_ITEMS.md)；細部尺寸及動畫數值為可調基線。

- 檔案模式的資料夾選擇需適合長路徑與大量資料夾。以資料夾名稱為主、單行省略的相對路徑輔助辨識，完整路徑可在 Hover／鍵盤聚焦時查看；支援名稱／路徑搜尋、鍵盤選取，選單高度受可視區限制並可捲動，不讓任意長路徑換行擠掉其他選項。同名資料夾保留來源區分，選取仍沿用既有授權與範圍。
- 屬性為遊戲時隱藏「檔案」檢視模式，維持資料夾瀏覽與遊戲專用內容。切換專案／分類或載入舊偏好時，若留有檔案模式需回退資料夾模式；不以隱藏入口取代遊戲 ROOT 的既有保護。
- 左側專案欄與右側內容欄的開啟／隱藏加入平順過渡，避免內容突跳；中途反覆切換、調寬及窄視窗不得造成殘留空間或焦點落在隱藏內容。遵循減少動態效果偏好；隱藏當下仍按既有規則停播／取消讀取，不延後到動畫結束。
- 資料夾候選一次最多顯示 100 筆，名稱／完整路徑搜尋仍涵蓋所有允許選取的資料夾；同名項目以相對路徑區分，鍵盤移動時提示完整路徑，無符合項目時顯示提示。側欄過渡只保留寬度容器，右側內容隱藏即卸載，隱藏區立即禁止焦點與操作；拖曳調寬不套開合過渡。
- 資料夾／檔案切換時，共用工具列組件的寬度與對齊保持穩定，不因切換內容而跳動；窄視窗仍依一致的響應式分組換行。
- 檔案模式的資料夾候選先按相對 ROOT 的深度升序（ROOT 為第 1 層），同深度按資料夾名稱的固定字元編碼序排序；同名以相對路徑穩定排序。搜尋篩選不改排序，截取可見候選前先排序，不採自然數字／語系排序。
- 專案 ICON 按遊戲、音樂、漫畫、圖片／相簿、影片等屬性區別，未知類型有通用回退；新增圖示沿用共用 SVG 風格。群組拖放完成後，項目移位有平順過渡，尊重減少動態效果偏好，保留排序保存與鍵盤操作。

## 專案設定與移除

各專案 ⋯ 選單開啟名稱／分類與連結資料設定；「移除」分頁有兩個按鈕（[C-122](DECISIONS.md#c-122移除專案改成兩個按鈕共用選項只在需要時出現2026-11-04)）：

- **從清單移除**：只取消連結，資料都留著，之後可用「新增專案」接回。
- **刪除這個專案的資訊…**：預設只刪這個專案的設定與私有資訊；勾選預設不勾的「也刪除這些資料夾裡 M:orph 建立的其他資訊」才完全移除，並列出也使用這些資料夾的已連結專案。

影響範圍、確認、備份與失敗復原由 [儲存安全](STORAGE_OPTIONS.md#移除單一專案) 持有。

## 設定包移轉

設定包是「應用程式設定 › 備份」裡 `settings.json` 的格式，不單獨匯出匯入（見 [DATA_FORMAT](DATA_FORMAT.md#備份資料夾2026-11-04)）：`media-viewer.settings` JSON，只含群組、收藏／專案排序、側欄、主題、語言、音量及瀏覽操作偏好；不含媒體、registry 路徑、單機 browse 位置或未知／登入欄位。還原時先預覽差異，預設合併保留目前同身分設定，可明確改為取代；媒體連結保持原樣。預覽 token 綁定目前 revision，過期需重看；較舊格式先升級（[DATA_FORMAT](DATA_FORMAT.md#格式升級與相容規則)）。

套用前先把目前 workspace 設定原子備份到 `userData/workspace-backups`，再保存；備份或保存失敗不切換記憶體狀態。還原設定後備份頁顯示「回到還原之前」，使用的就是這份存檔（[C-125](DECISIONS.md#c-125還原不再自動建立備份只為設定提供退路2026-11-04)）。還原不掃描或遷移實際收藏；雲端同步延後。入口 `electron/settings-package.ts`、`electron/backup.ts`、`electron/workspace.ts`、ApplicationSettings；驗證 `tests/decided.test.ts`、`tests/backup-ui.ts`。
