# 需求清單

只放還沒結束的需求；完成並查收的需求刪除（內容在 [CHANGELOG](../CHANGELOG.md) 與 git 歷史）。核定規則由規格持有，按 [任務索引](README.md#按任務定位) 選讀；流程規則在 [CLAUDE.md](../CLAUDE.md)。`pnpm status` 依本頁印出狀態區塊。

**格式**：`- **R-編號** 標題 ｜大小｜風險｜資料影響｜領域：id（見 [areas.json](areas.json)）｜依賴：R-…｜取代：…`，下一行縮排寫補充（可省略）。

- **大小**：小／中／大。
- **風險**：一般／資料寫入／安全邊界（後兩者提交前獨立審查，同批合併審一次）。
- **資料影響**：無／設定（專案或本機設定）／新增欄位（選用，不升格式；畫面查收前標「暫定」）／改結構（升格式，附升級步驟、舊格式樣本與測試，需核定）。
- **狀態**就是所在的章節；編號從 R-201 起，不與歷史 R／T／UI-R 提案混用。

## 待查收

- **R-261** 沉浸閱讀右緣拉出佇列 ｜中｜一般｜無｜領域：reader｜依賴：無
  驗收：從媒體頁開漫畫進沉浸閱讀，滑鼠移到右緣滑出佇列（可點選跳頁），離開收起。從其他地方開的閱讀器沒有佇列，右緣不會有東西。
  滑鼠移到右側邊緣（短延遲）滑出 `MediaQueue`，離開收起。
- **R-255** 讀完接下一本 ｜中｜一般｜無｜領域：reader、browse｜依賴：無
  驗收：在瀏覽區選一個漫畫資料夾開始閱讀，翻到最後一頁再按下一頁：出現「已是最後一頁／下一本：XXX · 再按一次下一頁開啟 [留在這裡]」；再按一次，右側面板換成下一個資料夾並從第一張開始閱讀。ESC 或「留在這裡」關掉提示。清單最後一個資料夾只顯示「已是最後一頁」。
  UI 測試涵蓋「已是最後一頁」提示與 ESC；實際切換到下一本沒有自動化測試（測試資料只有一個資料夾），請手動確認。媒體頁的檢視器沒有同層清單，不提供下一本；沉浸閱讀中切換後會回到一般閱讀（全螢幕需要使用者操作才能再進入）。下一本先不顯示縮圖。
- **R-271** 漫畫／圖片佇列加清單／圖片切換 ｜小｜一般｜無｜領域：media｜依賴：無
  驗收：從媒體頁或資料夾打開圖片／漫畫，打開右側佇列，標題列有清單／圖片切換；圖片模式只有縮圖，滑鼠停留看到檔名。
  媒體檢視器的佇列對圖片與漫畫也提供清單／圖片兩種呈現（原本只有影片有），圖片模式只顯示縮圖、檔名在提示。
- **R-272** 拖動圖片出現殘影、之後點不動 ｜小｜一般｜無｜領域：appearance、gallery、reader｜依賴：無
  驗收：在資料夾的瀑布流按住縮圖稍微拖一下再放開，不再出現半透明殘影，打開的檢視器可以正常點擊與拖動。UI 測試會實際拖動縮圖與頁面，檢查瀏覽器沒有開始原生拖動（修正前失敗）。
  原因：瀑布流縮圖可被瀏覽器原生拖動，點縮圖時手一動就開始拖，殘影蓋在剛打開的檢視器上並吃掉滑鼠事件。改為全域讓圖片不能被原生拖動；拖動排序的清單用列本身拖動，不受影響。
- **R-273** 播放順序提示看得到並寫出下一個狀態 ｜小｜一般｜無｜領域：media｜依賴：無
  驗收：開一首音樂，滑鼠停在控制列的播放順序按鈕上看得到提示，例如「播放順序：播完停止（按一下改為接續下一首）」；佇列標題列那顆一樣。
  音樂控制列的播放順序按鈕提示被播放器蓋住（沒設圖層），補上；提示改為「播放順序：目前狀態（按一下改為下一個狀態）」。
- **R-274** 沉浸閱讀的邊緣面板點過後收不起來 ｜小｜一般｜無｜領域：reader、media｜依賴：無
  驗收：沉浸閱讀時從左緣、下緣、右緣叫出面板，點裡面的按鈕（包含佇列的清單／圖片切換），滑鼠離開後面板會收起。UI 測試涵蓋左側工具列。
  左側工具列、下方進度條、右側佇列以「滑鼠停留或焦點在內」保持打開；滑鼠點按鈕後焦點留在面板內，滑鼠離開也不收。改為只有鍵盤焦點（focus-visible）讓面板保持打開。
- **R-275** 沉浸閱讀中換下一本保持沉浸 ｜小｜一般｜無｜領域：reader、browse｜依賴：無
  驗收：在瀏覽區的漫畫資料夾進沉浸閱讀，讀到最後一頁按兩次下一頁：換到下一本後仍是沉浸閱讀（全螢幕、介面隱藏）。沒有自動化測試（測試資料只有一個資料夾），請手動確認。
  原本舊閱讀器關閉時退出全螢幕，新閱讀器無法自動再進入。改為換下一本時不退出，新閱讀器發現視窗仍是全螢幕就直接進入沉浸閱讀；下一本沒有圖片可讀時退出全螢幕。
- **R-276** 第二次按住拖動仍出現殘影 ｜小｜一般｜無｜領域：reader、media｜依賴：R-272
  驗收：在閱讀頁面第一次按住拖動、放開，第二次再按住拖動，不出現殘影。UI 測試照這個步驟檢查沒有開始原生拖動、也沒有選取任何內容。
  第一次按住拖動會在閱讀區選取內容（不顯示），第二次按在選取內容上拖動就變成拖動選取內容而出現殘影。閱讀區與佇列禁止選取。
