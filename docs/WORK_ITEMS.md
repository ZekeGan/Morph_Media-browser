# 需求清單

只放還沒結束的需求；完成並查收的需求刪除（內容在 [CHANGELOG](../CHANGELOG.md) 與 git 歷史）。核定規則由規格持有，按 [任務索引](README.md#按任務定位) 選讀；流程規則在 [CLAUDE.md](../CLAUDE.md)。`pnpm status` 依本頁印出狀態區塊。

**格式**：`- **R-編號** 標題 ｜大小｜風險｜資料影響｜領域：id（見 [areas.json](areas.json)）｜依賴：R-…｜取代：…`，下一行縮排寫補充（可省略）。

- **大小**：小／中／大。
- **風險**：一般／資料寫入／安全邊界（後兩者提交前獨立審查，同批合併審一次）。
- **資料影響**：無／設定（專案或本機設定）／新增欄位（選用，不升格式；畫面查收前標「暫定」）／改結構（升格式，附升級步驟、舊格式樣本與測試，需核定）。
- **狀態**就是所在的章節；編號從 R-201 起，不與歷史 R／T／UI-R 提案混用。

  同類資料、不同來源的欄位整理成群組（例：遊戲標題 =〔來源1 TITLE → 來源2 TITLE → 來源3 タイトル〕）。建立／加入：欄位拖到另一欄位上建立、拖到群組上加入、「⋯ › 加入群組 ›」、多選後「組成群組」；型別不合不能放並說明；誤操作可復原。加入後從原來源分類搬進群組（一個欄位只屬一個群組），移出回原位；表格、搜尋語法、資料夾設定仍可單獨使用成員；成員可單獨拖上卡片。外觀：群組列與欄位列同樣式，圖示底色為強調色，排在「你的欄位」最上方，次要資訊是實際顯示值；點擊進入式打開（返回鍵），內可排順序、移出、✓ 標顯示中來源。顯示：依順序取第一個有值；個別資料夾在資料夾設定指定來源（存專案設定、以資料夾 ID 對應，不跨專案；指定來源變空時暫依順序並說明，被移出或刪除時清除）；都沒值就是空的。右側內容分頁拿掉綁定欄位清單，改「顯示：群組『…』［更換］」。解散或移出最後一個成員時組件改綁第一個成員；只剩一個成員時保留群組。管理欄位同一套手勢，群組詳細含成員、各資料夾顯示來源統計、用在哪裡、解散。搜尋任一成員符合即找到；表格與排序用實際顯示值；卡片滑鼠提示來源；資料夾設定並排各成員值。舊組件備用來源照讀，編輯時可「轉成群組」。只存在專案設定（選用欄位，先標暫定），不改資料夾記錄、不升格式；涉及搜尋索引與刪除欄位清理，提交前獨立審查。不做：語意標記、自動建議、語言偵測。
