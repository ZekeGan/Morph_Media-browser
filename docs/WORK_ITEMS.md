## 待查收與限制

- **拖放類 UI 測試怕滑鼠干擾**：`pending-ui` 的側欄群組拖曳在跑測試時移動滑鼠會偶發失敗，空機重跑通過；跑 UI 測試時請不要操作滑鼠。
- **appearance-ui 耗時不穩**：同一測試曾耗時 31／219／549 秒（0.13.5～0.17.0），其他測試正常；成因未查（疑與逐檔 ffmpeg 產圖或主題／語系輪巡等待有關），列為測試債。
- **0.20.0 遊戲偵測待查收**：新增日系視覺小說引擎規則，實測（唯讀）`D:\Media\gal` 的 14 個遊戲根原本只有 4 個被辨識，現在全部辨識。我沒有對該資料夾執行掃描或寫入；請你在應用程式內重新掃描／開啟該專案確認，已存在於遊戲內部的 `.media-viewer` 記錄會原樣保留。其他引擎（如 Livemaker、CatSystem2、Majiro、Kaleido）尚無樣本，未納入。
- **0.21.0 UI 稽核項目已處理**：影片播放失敗說明與外部開啟、遊戲頁候選確認與啟動提示、編輯器新增欄位按鈕與用語統一、右側面板返回／前進僅在覆蓋中央時顯示、紙色分頁對比、樹狀圖小地圖、最愛空區塊、搜尋對話框說明、建立專案狀態列、窄視窗遮罩。尚未涵蓋：HEVC／AC3 等編碼的轉檔（需附帶 ffmpeg，未核定）。
