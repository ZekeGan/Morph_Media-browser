## 待查收與限制

- **拖放類 UI 測試曾怕滑鼠干擾**：測試視窗現在是全透明、可點穿、不取得焦點（見 [IMPLEMENTATION](IMPLEMENTATION.md)），預期不再受你操作滑鼠影響；尚未專門驗證，`pending-ui` 的側欄群組拖曳若仍偶發失敗，runner 會自動重跑一次並標為 FLAKY。
- **appearance-ui 耗時**：正常約 30 秒；曾因視窗被當成隱藏而慢到 590 秒，現改用透明視窗已恢復。
- **0.20.0 遊戲偵測待查收**：新增日系視覺小說引擎規則，實測（唯讀）使用者的日系視覺小說收藏中的 14 個遊戲根原本只有 4 個被辨識，現在全部辨識。我沒有對該資料夾執行掃描或寫入；請你在應用程式內重新掃描／開啟該專案確認，已存在於遊戲內部的 `.media-viewer` 記錄會原樣保留。其他引擎（如 Livemaker、CatSystem2、Majiro、Kaleido）尚無樣本，未納入。
- **0.21.0 UI 稽核項目已處理**：影片播放失敗說明與外部開啟、遊戲頁候選確認與啟動提示、編輯器新增欄位按鈕與用語統一、右側面板返回／前進僅在覆蓋中央時顯示、紙色分頁對比、樹狀圖小地圖、最愛空區塊、搜尋對話框說明、建立專案狀態列、窄視窗遮罩。尚未涵蓋：HEVC／AC3 等編碼的轉檔（需附帶 ffmpeg，未核定）。
- 窄版遊戲頁工具列（< 620px 篩選改為圖示選單）未做自動化，已用截圖確認寬版。
- 聲卡實際輸出、滑鼠側鍵實體裝置及其他平台已由使用者查收範圍外，Mac 原生啟動未交付。
- 真實網站／登入、遊戲／媒體變體、跨設備硬故障需樣本與環境；遊戲未知變體保留人工 ROOT／not-game，不重掃或清理真實收藏。
- 完全移除須影響預覽、樹外備份、未知資料保留與失敗復原；復原包在 userData/maintenance-backups，見 [儲存安全](STORAGE_OPTIONS.md)。

- **大型類別已按功能拆開（0.37.1）**：`Library`、`Explorer` 的方法搬進同層模組（見 [架構](ARCHITECTURE.md)），類別保留轉呼叫的薄包裝，呼叫端不變；成員不再是 `private`，模組以第一個參數取得實例。`BrowseWorkspace.tsx`、`FolderPanel.tsx` 仍各約 1000 行，之後再拆。
