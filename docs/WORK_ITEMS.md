# 需求清單

只放還沒結束的需求；完成並查收的需求刪除（內容在 [CHANGELOG](../CHANGELOG.md) 與 git 歷史）。核定規則由規格持有，按 [任務索引](README.md#按任務定位) 選讀；流程規則在 [CLAUDE.md](../CLAUDE.md)。`pnpm status` 依本頁印出狀態區塊。

**格式**：`- **R-編號** 標題 ｜大小｜風險｜資料影響｜領域：id（見 [areas.json](areas.json)）｜依賴：R-…｜取代：…`，下一行縮排寫補充（可省略）。

- **大小**：小／中／大。
- **風險**：一般／資料寫入／安全邊界（後兩者提交前獨立審查，同批合併審一次）。
- **資料影響**：無／設定（專案或本機設定）／新增欄位（選用，不升格式；畫面查收前標「暫定」）／改結構（升格式，附升級步驟、舊格式樣本與測試，需核定）。
- **狀態**就是所在的章節；編號從 R-201 起，不與歷史 R／T／UI-R 提案混用。

- **R-232** 內容分頁整理 ｜中｜一般｜無｜領域：editor、cells｜依賴：無
  ①拿掉「找顯示後面欄位的資料夾」。②「顯示複製按鈕」只給文字、網址、多個值，收進內容分頁最下方的「其他選項」摺疊區。③顯示方式統一成切換鈕：文字／多個值是文字／標籤，單選與是／否是文字／徽章，數字是數字／星等／進度條；標籤顏色、顯示分類前綴搬到顯示方式下面。④沒有內容設定的組件（空白間距、分隔線…）不顯示分頁列，直接是樣式。⑤拿掉「條件」分頁：內容分頁加「沒有值時隱藏」勾選，其他條件收進「其他選項」的「只在…時顯示」；資料格式不變。⑥單選：選項清單只在管理欄位編輯（右側改［編輯選項］打開欄位詳細）；選項顏色只在顯示方式為徽章時出現，註明所有組件共用。
- **R-233** 樣式分頁重組 ｜中｜一般｜無｜領域：editor、cells｜依賴：R-232
  分三段：文字（預設展開：字級、粗細、斜體／底線／刪除線圖示、水平與垂直對齊圖示、顏色、行距、字距）、外框（預設收合，標題摘要已改項目：背景含「無」取代「背景透明」勾選、邊框、圓角、內距、透明度）、位置與大小（收合）。和預設不同的設定標小點，每段可「重設這段」。預設樣式選單只負責套用，存成／刪除／清除收進「⋯」。
- **R-234** 欄位用途：日期合併、是／否自訂文字 ｜小｜一般｜新增欄位｜領域：editor、cells、panel｜依賴：R-232
  ①新增欄位的「日期」與「日期和時間」合成一張「日期」卡加「包含時間」勾選（底層型別不變）；「改成…」也可切換，含時間的值改成只有日期時先提醒。②是／否欄位可在欄位詳細設定「是」「否」的顯示文字（各 1～20 字，留空用預設；暫定），卡片、表格、資料夾設定的開關、搜尋都用同一組文字；另可選「否的時候不顯示」。資料夾記錄仍存 true／false。
