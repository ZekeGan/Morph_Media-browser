# 小說閱讀器

> 最後確認：2026-11-12。文字書（TXT、EPUB）的閱讀規則。程式：`src/novel/NovelReader.tsx`、`src/novel/NovelContent.tsx`、`electron/novel.ts`、`shared/novel.ts`；測試：`tests/novel.test.ts`、`tests/novel-ui.ts`。圖片漫畫的閱讀器見 [MANGA_VIEWER_DESIGN](MANGA_VIEWER_DESIGN.md)。

## 範圍與分類

- `.txt` 與 `.epub` 是「文字書」（檔案類型 `text`）。不新增資料夾分類：檔案以文字書為主的資料夾判斷為「書籍／漫畫」（R-282 決定不動資料結構）。右側內容頁把文字書列成按鈕，點了開小說閱讀器；媒體大視窗與「檔案」總覽也能開。
- 只讀檔案，不改寫、不轉檔。EPUB 不執行內含的程式或樣式。

## 讀取（main）

- **TXT**：有 BOM 照 BOM；能以 UTF-8 完整解碼就用 UTF-8；否則在 Shift_JIS、GBK、Big5、EUC-JP、EUC-KR 中挑替換字元最少、假名或漢字最合理的。超過 32 MB 不開。章節依單獨成行的標題切開（`第一章`、`第12話`、`Chapter 3`、`プロローグ`、`序章`、`番外編`…，最長 50 字）；沒有標題的長文每約兩萬字切一段，章名顯示「第 N 部分」。
- **EPUB**：沿用唯讀 ZIP 讀取（不支援加密、ZIP64，路徑不得離開封包）。依 `container.xml` → 套件檔的 spine 排章節，章名取 EPUB 3 導覽文件或 EPUB 2 NCX。圖片經既有的壓縮檔圖片串流提供，只限封包內的圖片。
- 章節內容交給畫面時是文字；畫面用 DOMParser 解析後只重建允許的文字元素（段落、標題、強調、ルビ、清單、表格、圖片等），連結變成一般文字，`script`、`style`、表單、影音等整段丟棄，不把 HTML 字串直接插進頁面。

## 閱讀

- **排版**：分頁或連續捲動；橫排或直排（直排時 `writing-mode: vertical-rl`，由右往左翻；半形一兩位數字、`!!`、`!?` 縱中橫）。網路小說的ルビ寫法（`｜漢字《かんじ》`、`漢字《かんじ》`）轉成 `<ruby>`。分頁用多欄排版，一頁剛好一個視窗寬（直排時一個視窗高），不在行中間切開。
- **設定**（存在這台電腦，不跟書走）：明體／黑體、字級 12～36、行距 1.2～2.6、邊界 0～20%、每行字數（自動或 5～60 字）、背景（米色、白色、深色；與介面主題無關，像桌上的一張紙）。
- **操作**：方向鍵、空白鍵、Page Up／Down 翻頁（直排時左鍵是下一頁），分頁模式下滾輪也翻頁、點畫面左右半邊翻頁；Home／End 到第一章開頭與最後一章結尾；章末翻頁進下一章，章首往回進上一章結尾。T／F11 沉浸閱讀（全螢幕、隱藏工具列），Esc 依序關提示、側欄、沉浸，最後退出。最後一頁再翻一次提示「已讀完」，有下一本文字書時再按一次開啟。
- **側欄**：目錄（跳章）、書籤（加入、跳到、刪除）、全文搜尋（列出各章符合處，點選跳到該處並以醒目色標出）。

## 閱讀紀錄

- 每本書的位置存在資料夾記錄 `details.novels`（以檔名為鍵，**暫定**）：章節、該章讀到的比例、全書比例（依各章長度加權）、最後閱讀時間與書籤。換章、每半分鐘與離開時保存；只有位置變了才寫。主程序以記錄當下的版本寫入，只改這本書的位置。
- 卡片「系統資訊」組件可選「閱讀進度」「最後閱讀」（資料夾內最近讀過的那本）；有閱讀紀錄的專案在表格多這兩欄，可排序。
