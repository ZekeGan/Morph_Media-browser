## 資料與畫布

三區各司其職：左側素材面板「找到並放上卡片」、中央畫布「看見並直接操作」、右側「設定」。拖入建立組件實例，不複製某資料夾的值。模板用版本化模型保存 ID、類型、attributeId、格線／尺寸及受支援樣式，不保存 React 或第三方 library 物件。

CARD 專案方案與單一資料夾指定既有方案共用穩定方案身分；漫畫資訊等內容模板共用編輯能力但版面分開。資料夾帶自己的值，由目的專案版面顯示；單筆資料編輯只改值。指定方案見 [單一資料夾指定方案](#單一資料夾指定方案)，任意單筆畫布覆寫仍延後。

## 操作區配置

上方工具列由左至右：方案（SELECT、新增方案、⋯）、預覽資料小選單、復原／重做、關閉與唯一主按鈕「儲存」。

組件、畫布、組件設定採可讀寬度；空間不足時將設定區移至畫布下方，再於窄視窗改成縱向排列，不把兩側表單壓窄。三欄並排時貼合視窗剩餘高度、各自捲動（組件與設定一律到底，畫布太長只捲畫布）；兩欄或一欄時整頁捲動。

空畫布的「從範本開始」疊在格線上方，不佔放置位置；拖曳經過畫布時淡出、離開或取消時淡入，放下第一個組件後不再顯示。

新增欄位以同一表單連接名稱 → 型別 → 新增，從「你的欄位」標題的「＋」、欄位管理視窗的「新增欄位」或搜尋不到時的「＋ 建立欄位『…』」（帶入搜尋文字）開啟；新增後出現在「你的欄位」，可點擊或拖入。表單是「名稱 → 點一張用途卡 → 新增」，用途見 [欄位用途](#欄位用途)。建立定義不寫入假資料。

素材面板分四區、同一標題樣式且可收合：資料夾資訊（名稱、路徑、系統資訊、圖片、開啟資料夾）、你的欄位、排版（版面文字、空白間距、分隔線）、遊戲（只在專案有遊戲或卡片已用遊戲組件時出現）。來源及使用次數見 [組件與欄位區](#組件與欄位區)。新增資料型組件須先建立／選擇欄位，不從泛型文字按鈕暗中建立定義。

資料夾記錄裡尚未加入本專案配置的欄位與專案欄位在同一來源組內：每組直接列出已加入的欄位，尚未加入的收成「＋ N 個尚未加入」，點開後名稱變淡；沒有已加入欄位的來源組預設收合（自建除外），搜尋或「只看有值」時全部展開。點擊或拖入即加入並建立組件，「⋯」的「只引用欄位」只加入專案配置。引用時保留 attributeId，不複製值，不列其他專案私有欄位；有型別衝突的來源停用。

加入專案時（放上卡片、只引用、加入群組）網站匯入的欄位用白話名稱加來源命名，例如 TITLE_ORIGINAL →「原文名稱（E-Hentai）」；對照表沒有的沿用鍵名，名稱已被欄位或群組使用時加「_2」等編號（R-236）。已加入的欄位不自動改名。

## 已確認互動與現行基線

- 工具列的預覽資料小選單（「使用真實資料預覽」）除了各資料夾，還可選「極端情況」的「各欄位最長的資料」「各欄位最短的資料」（從所有資料夾挑出每個欄位最長／最短的非空值，名稱與路徑亦同），用來檢查版面的極端情況。同組還有「範例資料」（只要有資料夾就提供）：每個欄位取任一資料夾的真實值，都沒有時依型別填示意值（文字、三個示意標籤、單選的第一個選項、數字 4、今天、是、範例網址），照組件真正的樣式顯示，畫布上方標示是示意值；不寫入任何資料。選取的欄位組件在所有資料夾都沒有值時，內容分頁提示並可「用範例資料預覽」。
- 預覽小選單兩側切換上一個／下一個資料夾。
- 圖片組件設成「填滿容器（裁切）」且圖片比例與框相差超過 20% 時，同樣標為被截掉，快速處理為「完整顯示」「模糊填滿」；模糊填滿的裝飾背景不算內容裁切。
- 畫布上方固定一行狀態：沒有截斷時顯示「預覽中沒有內容被截掉」，有則顯示數量。被截掉的組件以橘色虛線框標示；選取它時同一行提供快速處理：「換行」（名稱、路徑、文字欄位）、「內容多時可捲動」（文字欄位、標籤、版面文字）、「加高一格」。可捲動的組件不算被截掉。
- 樣式區的「套用預設樣式」分「內建」與「此專案的樣式」；「存成樣式…」把目前組件的整個樣式（含顏色）以名稱存在此專案（最多 20 個，名稱不可重複），「刪除樣式…」移除；隨版面一起保存，不跨專案共用。

- 保留 react-grid-layout 作格線拖放／調整尺寸引擎。固定邏輯格線，窄視窗減少每列筆數或換行；不能裁掉內容。
- 預設碰撞推開；沒有合法空間就拒絕並提示，不越界。不預設允許重疊／圖層，任意 CSS／腳本未納入。
- 新增分隔線組件；選取組件時畫布上浮出複製／移除小工具列（在組件右上角上方，沒有空間時在角內）。Delete 移除、Ctrl+D 複製目前選取的組件，Esc 或點畫布空白處取消選取；輸入框／選單輸入與中文組字不攔截，支援復原／重做。
- 右側設定分「內容／樣式」兩分頁，記住上次的分頁（本機設定）；沒有內容設定的組件（名稱、路徑、空白間距、分隔線、開啟資料夾）不顯示分頁列，直接是樣式。位置與大小的數值輸入在樣式底部的「進階：位置與大小」。
- 內容分頁（R-232）：「顯示：…［更換］」→「顯示方式」切換鈕（文字與多個值：文字／標籤，標籤時另有標籤顏色與分類前綴（只在這個欄位的資料有「分類:標籤」格式、或已設定過時出現，R-238）；單選與是／否：文字／徽章；數字：數字／星等／進度條，星等與進度條另有滿分）→ 組件專屬設定 →「沒有值時隱藏」（沒有值的欄位組件在卡片與預覽一律顯示淡色的「沒有值」，勾選則留白，R-237；等於條件「這個組件的欄位有值」；群組或備用來源組件看實際顯示的值）→ 收合的「其他選項」：顯示複製按鈕（只限文字、網址、多個值）與「只在…時顯示」的完整條件（最多 5 個，兩個以上時可選全部符合／任一符合；日期欄位另有距今 N 天內／超過 N 天，R-239）；版面文字另有「依條件顯示文字」規則清單，下方的文字框變成「其他情況顯示的文字」；已有其他條件或已開複製按鈕時自動展開，換組件時收回。單選的選項只在管理欄位編輯（右側是［編輯選項］）；顯示方式為徽章時才有選項顏色，並註明所有組件共用。沒選組件時顯示「整張卡片」：組件數、被截掉的組件清單（點選即選取）與操作提示。
- 圖片是選用組件，可新增多個獨立圖片位置；保存版面後在資料夾設定的「圖片」頁分別選圖／匯入，沒有設定可留空。不為所有資料夾建立必填圖片欄位。
- 支援選取、刪除、位置／尺寸數值輸入、真實資料夾預覽、取消、未保存保護與多步復原／重做。空值用佔位，不寫假資料；保存成功即套用。
- 新專案先有可用模板。文字與背景色是目前基本樣式，背景預設透明；格線數／限制以 shared 驗證與 Editor 為準，不當成永久產品尺寸。
- 字級、粗細、對齊、內距、邊框、圖片裁切、自訂色碼等是已確認的可擴充方向，未交付細節仍需分期，不宣稱整套設定均已存在。

改動時驗證涉及的拖入／碰撞／尺寸／保存／取消及真實資料綁定；共用引擎變更才補其他模板，不每次重跑所有媒體。原驗收例子與待選細節保存在 [原稿](history/agent-docs-before-cleanup.md#editor-design)。

## 組件與方案管理

方案管理只適用卡片，漫畫資訊模板沿用共用編輯能力；組件與欄位型別契約集中 [CELL 目錄](CELL_CATALOG.md#新增組件與型別)。

### 組件與欄位區

- 每列同一樣式：圖示（組件用圖示、欄位用型別符號）與名稱。組件列只有一行，用途在滑鼠提示；欄位列第二行是預覽值（沒有預覽時是型別）。尚未加入的欄位右側標「尚未加入」，已加入的不標次數（使用次數只在管理欄位：含所有方案與內容模板，只算顯示這個欄位本身或當備用的組件，群組的組件算在群組；滑過列出各版面的次數，例如「目前版面 2、遊戲資訊版面 1」）；右側還有「⋯」（只引用欄位、重新命名欄位、刪除欄位及資料；未保存版面時刪除停用並說明）。專案私有與有專案覆寫另標小徽章，完整的型別、來源與共用範圍在滑鼠提示。
- 「你的欄位」按來源分組並可收合（沿用 `src/editor/fieldSources.ts`），順序固定為「群組 → 自建 → 各網站依名稱」，與欄位管理視窗相同；群組見 [欄位群組](#欄位群組)。欄位列「⋯」另有「欄位設定…」直接開欄位管理的該欄位詳細。標題列由左至右：「只看有值」、⚙ 管理欄位、＋ 新增欄位。引用後保留來源標示，來源不強制加進欄位別名。
- 面板頂端一個搜尋框比對組件名稱與用途、欄位名稱與來源（按來源篩選即搜尋來源名）。「只看有值」切換鈕在「你的欄位」標題列（只作用於欄位；收合時仍可切換），只留預覽資料夾有值的欄位，該區頂端顯示隱藏數量並提供「顯示全部」；沒有預覽資料夾時停用。篩選不移除畫布或備用來源。來源身分與共用範圍分開；手動修改網站欄位不改變原網站身分。
- 空白畫布提供「從範本開始」與「加入第一個組件」入口；還沒有欄位時「你的欄位」提供「加入常用欄位」。
- 基礎組件與資料型別使用 CELL 目錄的契約；沒有群組組件。

### 欄位管理視窗

從「你的欄位」標題列的 ⚙ 或欄位列「⋯ › 欄位設定…」開啟（`src/editor/FieldManager.tsx`）。用途是一次看全部欄位並仔細設定；放上卡片仍用左側清單。這點寫在搜尋框旁的 `?` 提示，並有搜尋（名稱、用途、來源）與「新增欄位」；群組（R-226）另有「新增群組」。

- **清單＋詳細**：左清單與左側「你的欄位」同一結構（群組在最上方，再按來源分組、固定順序；尚未加入收成「＋ N 個尚未加入」，沒用到的來源預設收合）。每列一行：圖示、名稱、用途短名、使用次數（含其他方案）。窄視窗一次一欄，點選進入詳細、有返回鍵。
- **欄位詳細**：名稱（改名）、用途與「改成…」（見 [欄位用途](#欄位用途)）、來源（點一下清單只留該來源）、資料例子（幾個資料夾有值、例舉值）、選項與選項顏色（只限單選；使用中的選項不能移除，每個最多 100 字）、所屬群組（移出或加入群組）、刪除（最下方；未保存版面時停用，先預覽影響，沿用 [自訂欄位刪除](#自訂欄位刪除)）。尚未加入的欄位只提供「只引用欄位」。
- **群組詳細**：見 [欄位群組](#欄位群組)。
- 手勢與左側相同（拖到欄位上建立群組、多選「組成群組」）。視窗內的改動與畫布一樣進編輯草稿，可復原，按「儲存」才生效；從視窗開啟的新增、改名、刪除對話框疊在視窗上方。

### 欄位用途

新增欄位直接選用途卡，每張附圖示與例子；底層型別不變、不升資料格式（`src/editor/fieldTypes.ts`）。

| 用途 | 例子 | 底層 |
|---|---|---|
| 文字 | 標題、作者、備註 | `string` |
| 多個值 | 類型、角色 | `tags` |
| 單選 | 狀態：進行中／已完成 | `enum` |
| 數字 | 評分、集數 | `number` |
| 日期 | 發售日；勾「包含時間」：最後遊玩 | `date`／`datetime` |
| 是／否 | 已收藏 | `boolean` |
| 網址 | 官網 | `url` |

- 新增欄位的「日期」卡下有「包含時間」勾選，決定是 `date` 或 `datetime`；清單與詳細仍分別顯示「日期」「日期和時間」。欄位詳細可「改成包含時間／改成只有日期」：組件跟著換呈現，條件比較值只留日期；有資料夾的值含時間時先提醒，已存的值不改寫，只有日期的組件只顯示日期部分。欄位在群組（多個成員）或備用來源中時不能切換並說明。
- **日期與文字互換**：日期／日期和時間欄位的「改成文字」與文字欄位「改成…」裡的「日期」「日期和時間」。改成文字時，日期組件換成文字組件，讀這個欄位的大於／小於／距今條件移除（確認前顯示數量），其他條件保留；已存的值照原樣顯示。改成日期時，所有已存的值都要讀得成日期（規則同 [外部匯入](METADATA_ENRICHMENT.md#預覽套用與追溯)，只有年份不算），否則列出讀不成的值並拒絕；用在「等於／不等於」且比較值不是日期時要先改條件。資料夾記錄不改寫，卡片、表格、排序、條件與搜尋都把文字讀成日期；資料夾設定用欄位目前的用途編輯，保存時才改存成該型別。欄位在群組（多個成員）或備用來源中時不能切換。
- 是／否欄位可在欄位詳細設定「是」「否」的顯示文字（各 1～20 字，留空用是／否），卡片、表格、資料夾設定與搜尋都用同一組文字。是／否組件的內容分頁另有「只在「是」時顯示」（條件：等於是）。

- 選「單選」才出現選項輸入，用標籤輸入：逗號（含全形，輸入法輸入的也算）或 Enter 建立一個選項，與管理欄位的選項輸入相同（`src/editor/OptionTagsInput.tsx`）。清單與詳細用用途短名顯示型別。
- **改用途**：欄位詳細的「改成…」只列可互換的文字、多個值、單選；確認前列出影響（幾個組件換呈現、已存的值不改寫、選項來源）。只改專案的欄位定義；資料夾記錄裡已存的值不改寫，顯示時轉換（文字與標籤互通規則見 [CELL 目錄](CELL_CATALOG.md)）。資料夾設定中，已存的值沿用原格式編輯並註明；尚未有值的資料夾依新定義輸入，多個值以半形或全形逗號拆分。
- 改成「單選」時，選項是先前保留的選項加上目前資料夾的不同值（每個 1～100 字、合計最多 100 種）；沒有值時先輸入選項；改離時保留選項供日後使用，但移除選項顏色。
- 切入或切出「單選」時，綁定此欄位的組件（含其他方案與內容模板）跟著換呈現，並移除新呈現不支援的設定；文字與多個值之間互換時組件保留原呈現。
- 做不到時說明原因、不能確認：欄位在備用來源鏈中、或與其他欄位同在一個群組時，不能切入或切出「單選」；用在「等於／不等於」條件時不能改成多個值，比較值不在選項內時不能改成單選。改用途只在卡片版面編輯器提供（會轉換所有方案與內容模板的組件），內容模板編輯器中停用並說明。

### 欄位群組

同類資料、不同來源的欄位可整理成群組，例如遊戲標題 =〔來源1 TITLE → 來源2 TITLE → 來源3 タイトル〕。群組只存在專案設定（選用欄位），專案內所有資料夾共用；不改資料夾記錄、不升格式。不做語意標記、自動建議與語言偵測。

- **整理（資料夾模型）**：把欄位拖到另一個欄位上建立群組（名稱預設為「第一個欄位名 群組」，建立後直接打開、可改名）、拖到群組上加入；也可「⋯ › 加入群組 ›」（含「新群組」）或多選（Ctrl＋點選或「⋯ › 選取」）後「組成群組」。群組名稱 1～100 字，不可與其他群組或任何欄位同名（搜尋語法以名稱指定，不能有歧義）。型別不合（同型別，或文字與標籤混用才可）時不能放下或停用並說明；誤操作可復原。加入後欄位從原來源分類搬進群組，一個欄位只屬於一個群組；移出（成員「⋯ › 移出群組」，管理視窗為 ×）回到原位。表格、搜尋語法與資料夾設定仍可單獨使用成員欄位；成員可從群組內單獨拖上卡片。
- **外觀**：群組列與欄位列同樣式，圖示底色為強調色，排在「你的欄位」最上方，次要資訊是目前預覽實際顯示的值；點擊進入式打開（取代欄位區、左上返回），內有名稱（旁邊 `?` 說明取值與加入方式）、「加到卡片」與依顯示順序排列的成員（拖曳或「⋯ › 上移／下移」排序、移出、✓ 標示預覽資料夾顯示中的來源）。群組「⋯」：群組設定…、重新命名、解散群組。
- **顯示**：依成員順序取第一個有值的來源，只顯示一個；個別資料夾可在資料夾設定指定顯示哪個來源（預設「自動（依群組順序）」，沒值的來源不能選；存在專案設定、以資料夾 ID 對應，不跨專案；指定來源變空時暫依順序並說明，被移出或刪除時清除）。都沒值時與其他未填欄位一樣是空的。卡片滑鼠提示列出來源與是否為個別指定；表格、排序、搜尋用實際顯示的值，搜尋語法以群組名稱指定，任一成員符合即找到（比較條件亦同），只寫成員名稱則只找該成員；「只看有值」依實際顯示的值判斷。
- **組件**：右側內容分頁只顯示「顯示：群組『…』［更換］」（單一欄位組件同樣是「顯示：欄位『…』［更換］」）；［更換］列出相容的群組與欄位。下方一行只說現在顯示哪一個與它的順位：「目前：原文名稱 · E-Hentai（第 1 個）」（名稱用匯入欄位的白話名稱加來源，沒有對照才用欄位名；滑過列出完整順序；沒有預覽時寫幾個欄位），旁邊［編輯群組］在左側打開該群組；舊版備用來源寫「備用來源（舊版）：N 個欄位」並有［轉成群組］。不列資料夾全名與箭頭鏈。解散群組或移出最後一個成員時，用到它的組件改綁第一個成員；只剩一個成員時保留群組。
- **資料夾設定**：群組並排列出成員與各自的值、各自可編輯（寫入各成員欄位），並有「這個資料夾顯示：自動／某來源」選擇（立即存入專案設定）。
- **群組詳細（管理視窗）**：名稱、成員（排序、移出、把清單中的欄位拖進來加入）、各資料夾實際顯示來源的統計（含沒有值與個別指定）、解散群組；用到它的組件數在清單列的「使用 N 次」提示。
- **舊資料**：組件既有的備用來源（`fallbackIds`）照常讀取，編輯時提示並可「轉成群組」，按下才轉換。刪除成員欄位時，影響預覽列出會從哪個群組移除。

### 方案管理

方案管理只處理版面方案的新增、修改、複製及刪除，不刪除組件／欄位資料。CARD 與漫畫仍共用編輯能力、版面分開，不因本項將 CARD 方案管理擴展為漫畫多方案。

- 編輯器上方以「方案 SELECT → ＋新增方案 → ⋯」集中管理；⋯ 提供複製、重新命名、刪除。右側保留關閉（有變更時為放棄變更）與唯一主按鈕「儲存」，移除「另存為新方案（保留原方案）」勾選框。
- 新增方案需命名並建立空白畫布；複製以目前畫布（包含尚未保存的畫布調整）建立副本再命名，保留原方案。名稱不可重複。
- 新增、改名、刪除與畫布調整先留在編輯草稿，按「儲存」才正式生效並套用目前選擇的方案；取消可放棄本次全部調整。保存失敗保留草稿供重試。
- 刪除只移除方案版面，保留欄位定義、資料夾值及圖片資產；刪除目前方案後切換到另一現有方案，清楚顯示接替對象。至少保留一個方案，只剩一個時停用刪除並說明原因。
- 切換方案遇到未保存的畫布修改時，提供「保存後切換／捨棄／繼續編輯」；已存在的未保存保護同樣適用關閉及取消。
- 復原／重做使用上方工具列的一組小圖示，與方案操作分組；Hover／鍵盤聚焦提示名稱及快捷鍵，沒有可用紀錄時停用。保留多步歷史，讓尚未保存的刪除等編輯可復原。

### 方案工具列對齊

方案 SELECT、新增方案與更多按鈕統一控制高度、底線對齊及間距，標籤不推歪相鄰按鈕；長名稱可省略並查看完整名稱，窄視窗採有序換行。復原／重做依下節在上方工具列分組，方案及草稿語意保持上述規則；驗收需含三主題與不同語系。使用者圖 1 的未對齊問題留在工作清單追蹤。

### 工具列與拖曳呈現

- 畫面分為上方工具列及下方實際編輯區。工具列集中儲存／關閉、方案、預覽資料與復原／重做，正常寬度盡量同列；窄視窗可按職責分組換行，不裁切或移除功能。下方維持組件、畫布及設定區，移除多餘說明。
- 拖曳組件的 Ghost Image 僅呈現該組件／來源項目，不包含上方標題、工具列或其他頁面內容；原生抓取點依滑鼠在來源內的位置計算，畫布拖曳以格線局部座標處理，涵蓋捲動與縮放；驗收從組件庫拖入及畫布內拖動，保持既有碰撞、尺寸與復原功能。

### 單一資料夾指定方案

單一資料夾可指定目前專案的既有版面方案，也可恢復跟隨專案預設；不支援單筆資料夾自訂畫布。此選擇只影響目前專案的顯示，不複製或改動共用欄位值。指定保存於本專案 folderLayouts，以 folderId 參照既有方案；清除即跟隨專案。刪除方案時移除其指定，失效參照回退專案版面；跨專案不搬用原專案指定，不影響欄位值與圖片。不寫入資料夾的可攜記錄。

資料夾設定中，此控制與實際欄位填值區使用分隔線或明確分區區別。SELECT 提供可明確選取的「遵循通用設定（此專案版面）」作為預設，不只靠空白 placeholder／清除按鈕表達繼承；遵循時不固定複製當下方案 ID，專案方案改變後持續跟隨。

### 自訂欄位刪除

提供實際刪除自訂欄位及其資料的管理動作，與「移除組件」只改版面明確區分。欄位身分依 attributeId 判斷，不把同名欄位當成同一欄位。

- 刪除前先預覽受影響的欄位數，另列資料夾數、欄位值筆數及方案／表格／漫畫版面／常用搜尋等引用數，分清計數單位；有其他專案共用時列出受影響專案。未填值不算一筆已有資料，0 與 false 是有效值，不可漏算。
- 使用者看到影響數量及範圍並確認後才刪除，即使沒有引用也需確認；取消不寫入。確認綁定預覽指紋，期間資料或引用變更需重看預覽。
- 刪除範圍中的欄位配置、值與引用需一致處理，不留下失效引用或自動綁到其他同名欄位。離線／未納入的資料不得宣稱已刪除；只顯示可證明範圍的數量及限制。引用此欄位的組件與整條常用搜尋一併移除，避免刪掉搜尋條件後意外擴大結果；預覽明示數量。已驗證的原位置備份獨立去除舊引用，復原副本留在樹外；未連結專案私有值及無法解析的無關舊查詢保留並列限制，疑似目標引用無法辨識時拒絕執行。
- 共用值／私有覆寫、受管資料所有權、備份與失敗復原依 [儲存安全](STORAGE_OPTIONS.md#清理與範圍) 處理；不刪除原始媒體或與欄位無關的資料。
